프로세스는 독립된 주소 공간을 가집니다. 스레드는 한 프로세스 안에서 코드·데이터·힙을 공유하고, 스택과 레지스터만 따로 가집니다.

| | 프로세스 | 스레드 |
|---|---|---|
| 메모리 | 독립된 주소 공간 | 힙·데이터 공유 |
| 통신 | IPC 필요 | 공유 메모리로 직접 |
| 생성 비용 | 큼 | 작음 |

스레드 간 통신은 빠르지만 **동기화 문제**가 생깁니다. 공유 자원에 접근할 때는 `mutex` 같은 잠금이 필요합니다.

```go
var mu sync.Mutex
var count int

func inc() {
    mu.Lock()
    defer mu.Unlock()
    count++
}
```

프로세스 간에는 격리되는 대신 통신 비용이 듭니다.
